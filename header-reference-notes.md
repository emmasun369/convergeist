# Header Reference Findings

The dark transparent treatment allows the dark green wordmark and menu icon to disappear against a dark jade hero at initial load. The preferred reference uses an immediate warm rice-paper header surface with a clearly legible jade route mark, near-black `CONVERGE` wordmark, cinnabar `IST` and station dot, plus a near-black mobile menu icon. The header should remain opaque from the first frame rather than waiting for scroll state.
